# Temple data

Temple records will be stored as small, maintainable data files rather than loading the original 25 MB candidate CSV into every visitor's browser.

Planned fields include:

- name_en / name_ml
- alternate names
- religion
- sect / tradition
- sacred focus / deity
- site category
- state / district / place
- latitude / longitude
- architecture
- history / significance
- historical figures / dynasties
- festivals and verified rituals
- opening status / hours
- official links
- image source / licence
- OSM / Wikidata identifiers
- source provenance
- last verified date
- verification level
- management / authority classification

Candidate datasets are discovery material only until records are independently verified.
